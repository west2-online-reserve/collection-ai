# Python 基础语法与编程技巧笔记

## 一、 基础容器
### 1.1 列表 (List)
*   **特点**：可以存储不同类型的元素；元素**有序**、可以**重复**、元素**可修改**。
*   **获取与修改**：
    *   正向索引：`s[0]`；反向索引：`s[-1]`。
    *   切片：`序列数据[开始索引:结束索引:步长]`。
    *   修改：`s[5] = "ABC"`。
    *   删除：`del s[6]`。
*   **遍历**：
    ```python
    for item in s:
        print(item)
    ```
*   **常用内置方法**：
    *   `append()`：在列表的尾部追加元素。 `s.append(10086)`
    *   `insert()`：在指定索引之前，插入元素。 `s.insert(0, 92)`
    *   `remove()`：移除列表中第一个匹配到的值。 `s.remove(75)`
    *   `pop()`：删除列表中指定索引位置的元素（未指定索引，默认删除最后一个）。 `s.pop(2)`
    *   `sort()`：对列表进行排序。 `s.sort()`
    *   `reverse()`：反转列表元素。 `s.reverse()`

### 1.2 字典 (Dict)
*   **特点**：以键值对 `key:value` 存储；键 (key) 不重复。`value` 可以为任意类型的数据，`key` 不能为可变类型（如 list, set, dict）。
*   **常用操作**：
    *   **添加**：`字典名称[key] = value`
    *   **删除**：`字典名称.pop(key)`（删除指定的key，并返回对应的value）；`del 字典名称[key]`（删除指定的键值对）。
    *   **修改**：`字典名称[key] = value`
    *   **查询**：
        *   `字典名称[key]`（根据key获取value）
        *   `字典名称.get(key)`（根据key获取value，更安全）
        *   `字典名称.keys()` / `.values()` / `.items()`

### 1.3 集合 (Set)
*   **特点**：唯一性、无序、不重复、可修改。`S1 = { ... }` 或 `S2 = set()`。
*   **常用方法**：
    *   `add()`：添加元素。
    *   `remove()`：移除指定元素（不存在将报错）。
    *   `pop()`：随机删除并返回元素。
    *   `clear()`：清空集合。
    *   `difference()` / `union()` / `intersection()`：差集 / 并集 / 交集。
    *   运算符：交集 `&`，并集 `|`。
    *   集合推导式：`[要往集合中添加的元素 for s in set1 if ...]`

### 1.4 元组 (Tuple)
*   **常用方法**：
    *   `count()`：统计某元素出现的次数。
    *   `index()`：查找某元素的索引位置（第一次出现的位置）。
*   **组包与解包**：`x, y, z = t2`

### 1.5 数据容器对比总结（核心笔记）
| 容器类型 | 有序性 | 重复元素 | 可变性 | 索引访问 | 切片操作 | 使用场景 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **字符串 (str)** | 有序 | 允许 | 不可变 | 支持 | 支持 | 文本处理 |
| **列表 (list)** | 有序 | 允许 | 可变 | 支持 | 支持 | 有序可重复数据集合 |
| **元组 (tuple)** | 有序 | 允许 | 不可变 | 支持 | 支持 | 固定数据记录 |
| **集合 (set)** | 无序 | 不允许 | 可变 | 不支持 | 不支持 | 去重数据集合 |
| **字典 (dict)** | 有序(3.7+) | key不允许 | 可变 | 不支持 | 不支持 | 键值对 |

## 二、 函数
### 2.1 函数基础与进阶
*   **函数定义**：组织好的、可重复使用的、用来实现特定功能的代码。
    ```python
    def 函数名(参数列表): # 多个参数用逗号分隔
        函数体
        return 返回值 # 多个返回值封装到元组之中
    ```
*   **传参方式**：
    *   位置参数、关键字参数（顺序不影响）。
    *   混用：位置参数位于关键字参数前面。
    *   默认参数：有默认值的参数，放在最后。
    *   不定长参数：位置传递 `*args`（元组，适用于数量不确定的数据）；关键字传递 `**kwargs`（字典，适用于处理数量不确定的键值）。
*   **作用域**：`global` 声明全局变量。
*   **递归调用**：指函数中自己调用自己的情况，**必须有终点**。
*   **函数嵌套调用**：遵循栈结构，先进后出。
*   **常用内置函数**：`sum()`（求和）、`len()`（获取长度/个数）、`min()`、`max()`、`round(x, 1)`（保留一位小数）。

### 2.2 匿名函数 (Lambda)
*   **语法**：`lambda 参数列表: 函数体`

### 2.3 装饰器 (Decorator)
*   **本质**：本质上是一个Python函数（或闭包），它可以让其他函数在不需要做任何代码变动的前提下增加额外功能。
*   **应用场景**：插入日志、性能测试、事务处理、缓存、权限校验等。
*   **语法**：使用 `@装饰器名` 语法糖，放在被装饰函数定义之前。
*   **代码示例**：
    ```python
    def my_decorator(func):
        def wrapper(*args, **kwargs):
            print("函数执行前...")
            result = func(*args, **kwargs) # 执行原函数
            print("函数执行后...")
            return result
        return wrapper

    @my_decorator
    def say_hello(name):
        print(f"Hello, {name}!")
        
    say_hello("Python") # 会自动触发前置和后置功能
    ```
*   **核心思想**：遵循“开放封闭原则”，即对扩展开放，对修改封闭。

## 三、 面向对象编程 (OOP)
### 3.1 基础概念
*   **对象**：特征（属性）和功能（方法）。
*   **类**：一组具有相同属性和方法的模板。
*   **对象（实例）**：基于类创建出来的实例对象。
*   **命名规范**：类名每个单词首字母大写，单词之间没有分隔符（如 `UserInfo`）。
*   **对象名** = 类名(参数列表)
*   查看对象属性字典：`print(c1.__dict__)`

### 3.2 属性分类
*   **实例属性**：属于每个具体对象的属性，各个实例独立。
*   **类属性**：属于类本身的属性，所有实例共享。

### 3.3 魔法方法 (Magic Methods)
*   **定义**：Python中提供的以双下划线开头和结尾的特殊方法，用于定义类的特殊行为，Python会在适当时机自动调用。
*   `__init__`：初始化方法。
    ```python
    class 类名:
        def __init__(self, 参数列表):
            self.属性名 = 参数值
    ```
*   `__str__`：字符串表示方法。
*   `__eq__`：比较两个对象是否相等（equal）。
*   `__lt__` / `__le__` / `__gt__` / `__ge__`：支持比较两个对象的大小（小于、小于等于、大于、大于等于）。

## 四、 文本处理
### 4.1 字符串 (str) 常用方法
*   `find()`：查找子串，返回第一次出现的索引位置，找不到返回 -1。
*   `count()`：统计子串出现的次数。
*   `upper()` / `lower()`：转换为大写 / 小写。
*   `split()`：按指定分隔符分割成列表。
*   `strip()`：去除两端的空白字符或指定字符。
*   `replace()`：将指定子串替换为新的子串。
*   `startswith()`：检查是否以指定子串开头，返回布尔值。
 
### 4.2 正则表达式 (re)
*   **定义**：一种用于匹配字符串中字符组合的模式，常用于文本查找、替换和格式验证。
*   **导入**：`import re`
*   **常用方法**：
    *   `re.match(pattern, string)`：从字符串**开头**进行匹配，匹配成功返回Match对象，失败返回None。
    *   `re.search(pattern, string)`：扫描**整个字符串**，返回第一个成功的匹配。
    *   `re.findall(pattern, string)`：返回所有匹配的子串列表。
    *   `re.sub(pattern, repl, string)`：将匹配到的字符串替换为指定内容。
*   **常用元字符（笔记要点）**：
    *   `.`：匹配任意字符（除换行符外）。
    *   `\d`：匹配数字。`\D`：匹配非数字。
    *   `\w`：匹配字母、数字、下划线。`\W`：匹配非单词字符。
    *   `*`：匹配前一个字符 0 次或多次。
    *   `+`：匹配前一个字符 1 次或多次。
    *   `?`：匹配前一个字符 0 次或 1 次。
    *   `{n,m}`：匹配前一个字符 n 到 m 次。
*   **特别注意**：使用正则表达式时，字符串前通常加 `r`，如 `r'\d+'`，表示原生字符串，防止转义字符冲突。
    ```python
    import re
    text = "My phone number is 12345678901 and age is 18"
    print(re.findall(r'\d+', text)) # 输出: ['12345678901', '18']
    ```

## 五、 代码格式
### 5.1 列表推导式
*   作用：快速生成列表。
*   示例：`num_list2 = [i for i in range(1,21)]`
*   带条件示例：`[i * 2 for i in range(1,21)]`
*   解包和组包：
    *   解包：`num_list = [*num_list1, *num_list2]`
    *   组包：`num_list = num_list1 + num_list2`

### 5.2 Type Hint (类型注解)
*   变量：`变量名: 数据类型`。例如 `scores: int`。
*   支持联合类型：`str | int`（两种类型）。
*   复杂结构：`scores: list[int] -> tuple[int, int, float]`

## 六、 进阶技巧
### 6.1 生成器 (Generator) 与 yield
*   **定义**：在Python中，使用了 `yield` 关键字的函数不再是普通函数，而是一个生成器（Generator）。
*   **核心特性（重要）**：
    *   调用生成器函数时，函数体内的代码**不会立刻执行**，而是返回一个生成器对象。
    *   生成器是**惰性求值**的（按需产生数据），每调用一次 `next()` 或遍历一次，才执行到 `yield` 处暂停并返回，下次调用时从暂停处继续执行。
    *   **优势**：非常节省内存。处理大量数据（例如读取超大文件）时，不需要一次性将所有数据加载到内存中。
*   **代码示例**：
    ```python
    def my_generator():
        print("开始执行")
        yield 1
        print("继续执行")
        yield 2
        
    gen = my_generator() # 此时不输出任何内容
    print(next(gen)) # 输出：开始执行 \n 1
    print(next(gen)) # 输出：继续执行 \n 2
    ```
*   **生成器表达式**：`(x for x in range(5))`
    *   与列表推导式 `[x for x in range(5)]` 的区别：列表推导式会立即计算并返回完整列表，占用内存；生成器表达式返回生成器对象，按需生成，节省内存。

## 八、 模块与包 (Module & Package)
### 8.1 模块 (Module)
*   **定义**：一个 `.py` 文件。
*   **作用**：提高代码复用性、降低开发门槛、避免命名冲突。
*   **内置模块**：`math`, `random`, `os`, `sys`, `re`，以及自定义模块。
*   **导入方式**：
    *   `import 模块名` (如 `import random, os`)
    *   `import 模块名 as 别名` (如 `import random as rd`)
    *   `from 模块名 import 功能名` (如 `from random import randint, choice`)
    *   `from 模块名 import 功能名 as 别名` (如 `from random import randint as rint`)
    *   `from 模块名 import *`
*   **`__name__` 变量**：Python中非常重要的内置变量，表示当前模块的名称。
    *   当模块**直接运行**时：`__name__` 的值为 `"__main__"`。
    *   当模块**被导入**时：`__name__` 等于模块的文件名（不含 `.py` 后缀）。
    *   经典用法：`if __name__ == "__main__":`
*   **`__all__` 变量**：控制 `import *` 导入哪些功能（不含 `.py` 后缀）。

### 8.2 软件包 (Package)
*   **定义**：本质是一个文件夹。
*   **导入包内模块**：
    *   `import 包名.模块名` (如 `import utils.my_fun`)
    *   `from 包名 import 模块名` (如 `from utils import my_fun`)
    *   `from 包名.模块名 import 功能` (如 `from utils.my_fun import log_separator`)
    *   `from 包名 import *` 
*   **注意**：通过 `from 包名 import *` 导入全部模块时，需要在 `__init__.py` 文件中添加 `__all__ = []`，控制允许导入的模块列表。

    import random
