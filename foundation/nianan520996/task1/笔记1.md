# pytho语法和编程技巧

## 基础容器
1. list
列表索引下标从0开始，可以通过append()方法添加元素，通过popp()方法删除元素
```python
list = [1,2,3,4,5]
list.append(6)
list.pop()
list.insert(0,99)#指定位置插入
list.remove(1)#删除指定元素
list.reverse()#反转
list.sort()#排序（升序）
list2=list[0:3]#索引应用
```

2. dict
```python
dict = {'name':'zhangsan','age':18}
dict['name']#通过key访问值
dict.keys()#获取所有key
del dict['name']#删除指定key
dict.clear()#清空字典
dict.get('name')#获取指定key的值，如果key不存在则返回None
dict['name2']='eb'#添加元素
dict.update({'name':'lisi'})#更新字典
```
## 函数
1. Lambda
```python
lambda x,y:x+y#lambda参数:函数体，写较短单行函数
```

2. 装饰器
```python
def decorator(func):
    def wrapper(*args,**kwargs):
        print('start')
        x=func(*args,**kwargs)#函数被加入这里
        print('end')
        return x
        return wrapper
@decorator#使用语法糖包装函数
def test():
    print('test')
```

### OOP思想
1. 封装
封装：将数据与操作数据的方法封装在一起，隐藏数据，只提供对外的接口

2. 继承
继承：子类继承父类的属性和方法，并扩展新的属性和方法

3. 多态
同一个方法可以有不同的实现
