# 函数
## Lambda 
一行写完 ``add = lambda x, y : x + y``
## Decorator
```Py
def decorator(func):
    def wrapper(*args,**kwargs):
        print(f'{func.__name__} is running.')
        result = func(*args,**kwargs)
        return result
    return wrapper
```
语法糖：``@decorator``

# 生成器
输入：
```Py
def generator(n):
    for i in range(n):
        print('before yield')
        yield i
        print('after yield')
gen = generator(3)
print(next(gen))
print('----')
print(next(gen))
```
输出：
```
before yield
0
----
after yield
before yield
1
```
