# 终端问题与 VS Code 运行按钮

## 1. 作业中遇到的终端问题

### 问题一：运行 Python 文件时找不到目标文件

终端里运行代码找不到目标文件，因为终端所在文件夹和我的 `.py` 代码文件不在同一个目录

使用 `cd` 命令切换所在文件夹，再执行运行命令。

### 问题二：程序报错如何自查

运行后出现 Traceback，先查看报错最后一行，判断错误类型，再根据报错的行数和文件定位问题

### 问题三：测试不同文件

为了单独测试某个功能，可以在终端运行对应的测试文件

### 问题四：不知道自己在哪个目录

刚打开终端就直接敲命令，结果文件找不到、git 报错

动手前要先执行 `pwd` 看当前目录，再用 `ls` 看目录里有什么

删除、移动、git 操作前要先确认位置

### 问题五：路径带空格没有加引号

直接写 `cd My Documents` 会失败，正确做法是加引号

### 问题六：cp 和 mv 用反

想复制文件，结果用了 `mv`，原文件直接消失了

`cp` 是复制，原文件保留

`mv` 是移动或重命名，原位置不再保留

### 问题七：不在仓库目录就执行 git

在任意目录敲 `git status`，会提示 `not a git repository`

先 `cd` 进入仓库根目录，再执行 git 命令

### 问题八：命令卡住时直接关窗口

命令卡住时，先按 `Ctrl + C` 中断当前命令，不要第一时间直接关闭终端窗口

## 2. VS Code 右上角的三角形运行按钮

### VS Code

VS Code 右上角的三角形按钮是 Run Python File

它会使用当前选中的 Python 解释器运行当前打开的 `.py` 文件

运行结果显示在终端里

按钮只是更方便，不是脱离终端运行
