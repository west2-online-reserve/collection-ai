# Pokemon Battle 宝可梦对战

## 项目介绍

这是一个使用 Python 编写的命令行回合制宝可梦对战游戏。玩家从 5 只宝可梦中选择 3 只组成队伍，电脑随机选择 3 只，双方轮流使用技能，直到一方队伍全部昏厥。

最低运行版本为 **Python 3.10+**。

## 与官方示例的关系

本项目在作业提供的 `Pokemon_Example` 基础上扩展。`Pokemon_Example/` 目录保留了原始示例代码，项目沿用 `Pokemon`、`Skill`、`Effect` 的继承结构，并扩展了属性、技能和状态效果。

## 游戏玩法

1. 按提示输入 3 个不同编号，组成玩家队伍。
2. 电脑从同样的宝可梦池中随机选择 3 只组成队伍。
3. 玩家选择首发宝可梦，电脑随机选择首发。
4. 每回合玩家输入技能编号行动，电脑自动选择技能。
5. 宝可梦昏厥后，玩家需要从存活队员中选择替补，电脑会自动换上存活队员。
6. 一方队伍全部昏厥时结束；双方同时全部昏厥时判为平局。

## 宝可梦

| 宝可梦 | 属性 | HP | 攻击力 | 防御力 | 闪避率 | 技能 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| 皮卡丘（PikaChu） | 电 | 80 | 35 | 5 | 30% | 十万伏特、电光一闪 |
| 妙蛙种子（Bulbasaur） | 草 | 100 | 35 | 10 | 10% | 种子炸弹、寄生种子 |
| 杰尼龟（Squirtle） | 水 | 80 | 25 | 20 | 20% | 水枪、护盾 |
| 小火龙（Charmander） | 火 | 80 | 35 | 15 | 10% | 火花、蓄能爆炎 |
| 小锯鳄（Totodile） | 水 | 90 | 30 | 12 | 15% | 泡沫、水枪 |

小锯鳄是本项目自行设计的宝可梦，使用水属性被动，并拥有能够造成畏缩的「泡沫」。

## 属性克制

| 属性 | 克制 | 被克制 |
| --- | --- | --- |
| 草 | 水 | 火 |
| 火 | 草 | 水 |
| 水 | 火 | 电 |
| 电 | 水 | 草 |

克制方造成的伤害翻倍，被克制方对克制方造成的伤害减半。

## 属性被动

- **草**：每回合结束时恢复最大 HP 的 10%。
- **火**：每次成功造成伤害后，攻击力提升基础攻击力的 10%，最多叠加 4 层。
- **水**：受到伤害时，有 50% 的概率减免 30% 的伤害。
- **电**：成功闪避敌人攻击后，立即随机使用一个技能反击；反击过程中不会再次触发闪避反击，避免无限连锁。

## 技能

| 技能 | 效果 |
| --- | --- |
| 十万伏特 | 造成 `1.4 × 攻击力` 的电属性伤害，10% 概率使目标麻痹 |
| 电光一闪 | 造成 `1.0 × 攻击力` 的伤害，10% 概率触发第二次攻击 |
| 种子炸弹 | 造成 `1.3 × 攻击力` 的草属性伤害，15% 概率使目标中毒 |
| 寄生种子 | 持续 3 回合，每回合吸取目标最大 HP 的 10%，并为施放者恢复实际吸取的 HP |
| 水枪 | 造成 `1.4 × 攻击力` 的水属性伤害 |
| 护盾 | 使下一次受到的伤害减少 50%，生效后消失 |
| 火花 | 造成 `1.0 × 攻击力` 的火属性伤害，10% 概率使目标烧伤 |
| 蓄能爆炎 | 第一回合蓄力，下一回合造成 `3.0 × 攻击力` 的火属性伤害；80% 概率烧伤，目标面对该技能时闪避率额外增加 20% |
| 泡沫 | 造成 `1.0 × 攻击力` 的水属性伤害，25% 概率使目标畏缩 |

## 状态效果

- **中毒**：持续 3 回合，每回合损失目标最大 HP 的 10%。
- **烧伤**：持续 2 回合，每回合受到 10 点固定伤害。
- **麻痹**：下一次行动被跳过，触发后解除。
- **畏缩**：下一次行动被跳过，触发后解除。
- 同类状态再次添加时会刷新持续时间，不会无限叠加。

## 伤害计算

- 普通技能伤害：`int(攻击力 × 技能倍率 × 属性倍率) - 防御力`，最低为 0。
- 水属性被动在减去防御力之前生效；护盾在减去防御力之后使伤害减半。
- 中毒、烧伤和寄生种子的固定伤害不计算防御力和水属性被动。
- HP 不会显示为负数，昏厥的宝可梦不能继续行动。

## 文件结构

```text
Pokemon_Battle/
├── main.py           # 程序入口
├── play.py           # 另一个入口，调用 Game.run()
├── game.py           # 队伍选择、回合流程、换人和胜负判断
├── pokemon.py        # 宝可梦基类、属性类和具体宝可梦
├── skills.py         # 技能实现
├── effects.py        # 中毒、烧伤、寄生种子、治疗等状态效果
├── Pokemon_Example/  # 官方示例代码（原样保存，供对照）
├── test_pokemon.py   # 属性、伤害、技能与被动测试
├── test_game.py      # 队伍选择与回合流程测试
└── README.md
```

## 运行方式

在项目目录运行：

```bash
python main.py
```

也可以运行：

```bash
python play.py
```

## 测试方法

```bash
python test_pokemon.py
```
