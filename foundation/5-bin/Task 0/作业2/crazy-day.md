# 我的疯狂一天

## 清晨：被 AI 闹钟唤醒

早上 7 点，我被手机里的 AI 助手叫醒。它没有播放普通铃声，
而是用机器人的声音说：“今天有 3 项任务，请立即起床！”

我打开窗帘，看见阳光洒在桌面上。虽然只睡了 6 小时，
但一杯 300mL 的咖啡让我重新充满了精神。

![咖啡](./咖啡.jpg)

### 第 1 个意外

我准备登录 [GitHub](https://github.com/)，却发现键盘的字母 `G` 失灵了。
我只好先复制其他文本中的字母，再把它粘贴到用户名里。

## 中午：代码开始反抗

中午 12 点，我写了一个计算午餐预算的 Python 程序。原计划只运行 1 次，
没想到它输出了 100 行结果。

```python
budget = 30
meal_price = 18

if meal_price <= budget:
    print("预算足够，还能加一杯果汁！")
else:
    print("今天还是吃三明治吧。")
```

排查 20 分钟后，我终于找到了原因：昨天的测试循环没有删除。
这次经历提醒我，运行程序前应该先阅读一遍代码。

### 午间任务清单

| 任务 | 计划用时 | 实际用时 | 结果 |
| --- | ---: | ---: | --- |
| 修复 Python 程序 | 10 分钟 | 20 分钟 | 完成 |
| 整理 Markdown 笔记 | 30 分钟 | 45 分钟 | 完成 |
| 阅读 Git 文档 | 40 分钟 | 25 分钟 | 完成 |

## 傍晚：城市里的大冒险

下午 5 点，我准备坐地铁回家，却在错误的车站下了车。
导航 App 显示，我距离目的地还有 4km。

我没有立即返回，而是决定沿着河边步行。路上遇到了 2 只橘猫、
1 位拉小提琴的街头艺人，还看到了一场突然开始的灯光秀。

### 意外的收获

这段路程让我记住了 3 件事：

1. 导航很有用，但偶尔走错路也会遇到惊喜。
2. 代码出错时，先冷静阅读报错信息。
3. 平凡的一天，也可以因为好奇心而变得疯狂。

## 夜晚：为今天存档

晚上 10 点，我把今天的经历写成这篇 Markdown 文章。
最后，我用下面的 Git 命令查看文件状态：

```bash
git status
```

屏幕上出现了 `crazy-day.md`，
这场忙乱又有趣的冒险也终于画上了句号。
