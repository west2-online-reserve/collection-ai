# Python3 赋值、浅复制与深复制

> 内容来源：本次学习对话，围绕宝可梦队伍的对象共享问题整理。
> 语义核对：[Python 官方文档：copy 模块](https://docs.python.org/zh-cn/3/library/copy.html)
> 整理日期：2026-10-18

## 作用

理解赋值与复制的区别，判断修改一份数据时，另一份数据是否也会变化。

变量可以理解为对象的名字。列表里的元素也可以指向其他对象，所以复制列表，不一定复制了里面的成员。

## 语法与参数

```python
import copy

b = a
b = copy.copy(a)
b = copy.deepcopy(a)
```

- `a`：待赋值或复制的对象。
- `copy.copy(a)`：取得浅复制结果。
- `copy.deepcopy(a)`：取得深复制结果；内部使用的 `memo` 参数通常不需要手动传入。

## 得到什么

以下以列表中装着字典或普通自定义对象为例：

| 操作 | 外层列表 | 内部对象 |
| --- | --- | --- |
| `b = a` | 同一个列表，没有复制 | 共享 |
| `b = copy.copy(a)` | 新列表 | 仍然共享 |
| `b = copy.deepcopy(a)` | 新列表 | 递归复制内部对象；不可变对象可能仍被复用 |

`is` 判断是不是同一个对象；`==` 通常比较内容是否相等。内容相等，不代表对象相同。

## 示例 1：赋值只是增加一个名字

```python
a = [{"name": "皮卡丘", "hp": 80}]
b = a

b[0]["hp"] = 10
b.append({"name": "杰尼龟", "hp": 80})

print(a is b)
print(a[0]["hp"])
print(len(a), len(b))
```

输出：

```text
True
10
2 2
```

双方指向同一份队伍，通过任意一个名字修改，另一个名字都能看到。

## 示例 2：浅复制只分开外层列表

```python
import copy

a = [{"name": "皮卡丘", "hp": 80}]
b = copy.copy(a)

b.append({"name": "杰尼龟", "hp": 80})
b[0]["hp"] = 10

print(a is b)
print(a[0] is b[0])
print(len(a), len(b))
print(a[0]["hp"])
```

输出：

```text
False
True
1 2
10
```

队伍名单有两份，但名单上的皮卡丘还是同一个对象。增删名单互不影响，修改共享成员的血量会影响双方。

## 示例 3：替换列表元素与修改内部对象不同

```python
import copy

a = [{"name": "皮卡丘", "hp": 80}]
b = copy.copy(a)

b[0] = {"name": "小火龙", "hp": 80}

print(a[0]["name"])
print(b[0]["name"])
```

输出：

```text
皮卡丘
小火龙
```

`b[0] = 新对象` 修改的是 b 列表中的一个位置；`b[0]["hp"] = 10` 修改的是该位置指向的字典。

| 浅复制后的操作 | 是否影响 a |
| --- | --- |
| `b.append(...)`、`b.pop()` | 否，修改 b 的外层列表 |
| `b[0] = 新对象` | 否，替换 b 的一个元素引用 |
| `b[0]["hp"] = 10` | 是，修改尚未分开的共享字典 |

## 示例 4：深复制后独立修改内部数据

```python
import copy

a = [{"name": "皮卡丘", "hp": 80}]
b = copy.deepcopy(a)

print(a == b)
print(a is b)
print(a[0] is b[0])

b[0]["hp"] = 10
print(a[0]["hp"], b[0]["hp"])
```

输出：

```text
True
False
False
80 10
```

## 示例 5：只有一层时，两种复制一样吗？

如果列表里全是整数、字符串等不含可变成员的不可变值，浅复制与深复制在常见修改操作中的效果通常一样。

```python
import copy

a = [1, 2, 3]
b = copy.copy(a)
c = copy.deepcopy(a)

b[0] = 100
c[1] = 200

print(a)
print(b)
print(c)
```

输出：

```text
[1, 2, 3]
[100, 2, 3]
[1, 200, 3]
```

整数本身不能被原地修改，赋值只是让副本中的位置指向另一个整数。

| 列表内容 | 两种复制的常见修改效果 |
| --- | --- |
| `[1, 2, 3]` | 通常一样 |
| `["皮卡丘", "杰尼龟"]` | 通常一样 |
| `[[1, 2], [3, 4]]` | 不同，内部列表可修改 |
| `[pokemon1, pokemon2]` | 不同，宝可梦实例可修改 |

判断重点是是否共享着将被修改的可变对象，不能只看有没有嵌套列表。

## 作业中的应用

队伍浅复制后，双方可能仍指向同一个宝可梦实例。对该实例执行 `self.hp -= damage`，双方都会看到血量变化，因为程序中只有这一只宝可梦。

即使 hp 是不可变整数，修改 `pokemon.hp` 仍然是在修改共享实例的属性。要建立独立的战斗状态，可以分别创建实例，或适当地深复制。

## 注意：深复制会保留一次复制内部的共享关系

```python
import copy

pokemon = {"name": "皮卡丘", "hp": 80}
a = [pokemon, pokemon]
b = copy.deepcopy(a)

print(b[0] is a[0])
print(b[0] is b[1])
```

输出：

```text
False
True
```

新副本与原对象分开，但副本的两个位置仍指向同一个复制出来的字典。不能假定对包含双方队伍的大结构做一次深复制，就会自动消除双方原本的共享。

深复制也不保证所有对象都变成新对象；不可变值可能被复用，自定义类还可以定义复制行为。按需要选择复制范围，不必对所有数据一律深复制。
