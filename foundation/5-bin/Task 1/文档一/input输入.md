**要求输入`a b`的形式**
方法1:

```
a, b = input().split()
print(int(a) + int(b))
```

方法2：

```
a, b = map(int, input().split())
print(a + b)
```

## 补充：输入之后还要校验

`input()` 返回字符串，`int()` 才负责转成整数。对菜单编号，需要检查格式、保护转换失败，再判断合法范围；无效输入应继续重试。
