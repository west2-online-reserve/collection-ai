## 建议阅读顺序

1. 先读 List、Dict，再读列表推导式和 Lambda，理解数据如何保存、筛选和排序。
2. 阅读 Class，再读 Magic Methods 和 OOP，把实例语法与对象职责联系起来。
3. 阅读 Decorator，理解函数如何被包装，以及参数和结果怎样传递。
4. 阅读 re，练习区分整串校验、局部查找与文本替换。
5. 阅读 Type Hint，区分类型约定、真正的数据转换和运行时检查。
6. 最后阅读 generator 与 yield，对照列表理解按需产生数据和一次性消费。

每篇可先看“作用”和“语法”，预测三个示例的输出，再运行核对，最后复述注意事项。已有的 enumerate 笔记仍保留，可配合列表菜单编号一起复习。
