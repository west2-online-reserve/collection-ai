# 终端的基本使用

### Pycharm 右上角的三角形运行按钮


**状态**：如果当前文件存在可执行代码，那么运行按钮会显式为绿色，否则灰暗

**作用**：用于执行文件代码

**用法**：显示高亮时可以直接点击三角形运行，默认为运行当前文件，也可以从旁边的按钮下拉，选定旁边三个小点进行形参配置，一般适用于后端的打包测试，因为后端程序的输出和普通的代码运行输出不太一样，当然也可以进行编辑配置，从而实现各种不同的执行操作。

### 运行

运行的结果一般都会显示在你的软件的下方的面板里，这个面板可以打开多个不同的功能，而运行结果显示在“运行”面板中

### 报错

python 的错误问题会在输出的红色的最后一行，而前面的一大堆报错输出以及链接分别指向不同的代码行。点击每个链接可以定位到相应的代码行。给定链接一般以“套娃”的形式出现，即第一行是当前执行遇到的问题代码行，第二行就深入到这行代码，找出它调用的出问题的属性、方法，以此类推……最后一行往往定位到问题的最直接位置

### 终端面板

可以通过终端面板进行插件的下载/删除、Git 等操作，很方便。不过如果想要 Git, 建议还是使用 Git Bash 来得快一些，Pycharm 的终端设计上是适配 windows, 但是实际应用可能会产生一些比较隐秘的 bug, 不如直接定位到源文件位置然后 Git Bash
