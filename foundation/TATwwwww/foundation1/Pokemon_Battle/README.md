## 属性克制

| 属性 | 克制 | 被克制 |
| ---- | ---- | ------ |
| 草   | 水   | 火     |
| 火   | 草   | 水     |
| 水   | 火   | 电     |
| 电   | 水   | 草     |
| 地面 | 电   | —      |

## 属性被动

| 属性 | 被动                                     |
| ---- |------------------------------------------|
| 草   | 每回合回复 10% 最大 HP                   |
| 火   | 每次造成伤害叠加 10% 攻击力（最多 4 层） |
| 水   | 受击时 50% 概率减免 30% 伤害             |
| 电   | 闪避成功时立即使用一次技能               |
| 地面 | 高防御                                   |

## 状态效果

| 效果     | 说明                                                 |
| -------- | ---------------------------------------------------- |
| 中毒     | 每回合损失 10% 最大 HP                               |
| 烧伤     | 每回合 10 点伤害，持续 2 回合                        |
| 麻痹     | 30% 概率无法行动，持续 3 回合                        |
| 寄生种子 | 每回合吸取对手 10% 最大 HP 并治疗施加者，持续 3 回合 |
