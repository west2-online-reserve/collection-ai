# 终端基本使用

## 1.作业中遇到的终端问题

### 问题一：运行python文件

终端里运行代码找不到目标文件，终端所在文件夹和我的py代码文件不在同一个目录。使用cd命令切换所在文件夹，再执行运行命令。

例如先用 `cd Pokemon_Battle` 进入作业目录，再用 `python main.py` 运行入口文件。`cd` 只负责切换当前目录，`python main.py` 才是调用 Python 解释器执行文件。

### 问题二：程序报错如何自查

运行后出现Traceback，先查看报错最后一行，判断错误类型，再根据报错的行数和文件定位问题。

### 问题三：测试不同文件

为了单独测试某个功能，可以在终端运行对应的测试文件，不必启动整个游戏

例如我用 `python test_status.py` 检查 Pokemon Battle 的状态和完整战斗流程。

## vscode/pycharm的三角形运行按钮

* VS Code：通过 Python 扩展和当前选中的解释器运行当前 Python 文件，通常会在集成终端中显示运行结果；它本质上仍是在执行 Python 命令。

* PyCharm：通过当前运行配置调用 Python 解释器执行程序，通常在 Run 窗口显示结果，并不等于一定在内置终端中运行。

## 学习总结

通过这次作业，我对终端使用有了更加深入的了解。我学会了使用命令运行python文件，也学会了通过cd命令切换目录。当程序报错时，可以根据Traceback信息找到错误位置并进行排查。此外，我还学会了通过运行不同的测试文件，单独检查程序的功能。

通过这次练习，我认识到终端不仅能运行程序，还可以帮助我们调试代码和提高开发效率。
