## 基础容器使用

### List(列表)使用

#### 基础
用[]表示，元素用 ， 隔开

#### 相关特性
- 索引：引用索引形式为[(数字)]，python中由0为第一位
- 切片：引用切片形式为[(起始):(终点):(步长)]，具体规则类似range函数
- for循环遍历：类似字符串，可以利用for循环遍历列表中的元素
- 获得长度：利用len函数获取列表长度
- 嵌套：列表可以嵌套列表，引用时逐层使用索引：[][][]...

#### 列表操作
- append函数：向列表最后一位追加元素
- insert函数：向列表指定位置插入元素，注意插入位置后的元素序号会顺延一位
- extend函数：向列表后再合并一个新的列表
- pop函数：弹出列表中给定索引对应的元素，并返回这个元素
- remove函数：直接删除列表中指定的元素
- 修改列表：直接利用索引

- sort函数：对列表进行升序(reverse=False)排序和降序(reverse=True)排序

- 循环删除建议：准备一个临时列表，从临时列表中查找要删除的元素，在原列表中删除


### Dict(字典)使用

#### 基础
表示为{}，以键值对形式存储数据,key必须是可哈希的
字典可嵌套字典，引用时与列表相似

#### 字典操作
- 增加数据：索引为key,输入value，如***[(key)]=(value)
        也可使用***.setdefault(key,value)增加元素，但该方法不能进行修改操作

- 修改数据：可同增加数据一样使用索引操作，value直接覆盖

- 删除数据：使用***.pop(key),通过key删除

- 访问数据：可直接通过key的索引(key不存在会报错)，也可使用***.get(key)(key不存在返回None)

- 遍历数据：1.可用for循环遍历key和value
         2.可以用***.keys()拿到所有的key
         3.可以用***.values()拿到所有的value
         4.可以用***.items()拿到key和value，同时可一并解包

- 循环删除：准备一个列表存放要删除的key，最后进行删除操作

### Decorator装饰器

#### 理论基础
函数可以赋值给变量，也可以赋值给另一个函数

#### 核心作用
在不改变函数原代码的基础上，给函数增加新功能

#### 运用示例
```python
def warpper(fn):                #warpper :装饰器 fn :目标函数
        def inner(*args,**kwargs):
                # 目标函数前的操作.....
                result = fn(*args,**kwargs)
                # 目标函数后的操作.....
                return result
        return inner 
        
# 使用示例

@warpper
def fn():
        # 目标函数内容

```

## 文本处理：re正则表达式

### 定义

描述文本模式的语言

可用于：

- 查找数字

- 验证格式

- 提取日期、号码等

- 替换文本

- 分割字符串

### 具体使用

使用模块：

```python

import re

text = "123456,1234,5678"

print(re.findall(r"\d",text))  # 通过findall函数查找数字，输出为列表

```

### 相关函数

- search(): 查找文本任意位置

- match(): 从字符串开头开始匹配文本

- fullmatch()： 要求字符串完全符合，可用于验证输入格式

## 进阶技巧：Generator生成器与yield

### Generator生成器

按需求产生所需元素，而不是提前保存全部元素，从而节省内存。

```python
# 普通列表一次性保存所有元素

numbers = [ i for i in range(1,100000)]

# 生成器按需要，在需要元素时才进行计算

numbers =(
        i
        for i in range(1,100000)
)
```

注意生成器只消耗一次，要重复遍历需要重新创建

### yield

#### 基本使用

写在循环体中，并引入生成器对象，执行：使用next()；当循环体运行至yield：返回yield的值，并暂停循环直至下次调用next()；再次调用next()时循环从yield语句开始。

```python

def count_up_to(n:int)->int:
        i =1

        while i<=n:
                yield i
                i +=1


# 先调用函数
counter = conut_up_to(5)

# 此时函数并未执行，再使用next()

next(counter)
next(counter)
next(counter)
next(counter)

# 没有更多值时会产生StopIteration

```

#### 进阶：yield from

可供生成器依次产生另一个可迭代对象的元素

```python

def fn():
        yield from [1,2,3]
        pass

```
