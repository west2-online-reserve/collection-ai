# Pokemon 大战！

*成为一位训练家！*

## 玩法介绍

*总之就是非常简单！*

- 共有五只宝可梦可供选择，在玩家选择好*不能重复*的三只宝可梦后，电脑随机选择三只宝可梦组建队伍与玩家进行对战

- 对战采用回合制，每一轮由玩家先手，当任意一方宝可梦倒下后，败方从队伍中剩下的宝可梦中选择一位继续战斗。若一方的宝可梦*全部倒下*，则战斗结束，仍有宝可梦存活的一方获胜。

- 每位宝可梦都具有攻击力、HP、防御、闪避率、属性等基本特质，拥有两个技能，不同属性之间存在*克制关系*，同时各个属性还具有不同的*特殊被动*。

- 内置多种*状态效果*，提供丰富多彩的战斗体验！

## 宝可梦介绍

*各种属性效果、经典御三家、还有一位神秘的原创宝可梦*

### 属性表

|属性名|克制|被克制|属性特质|
|---|---|---|---|
|草|水|火|每回合结束时，若宝可梦存活，则回复最大HP10%的血量|
|火|草|水|若攻击造成*未被格挡*的伤害，攻击力额外叠加10%，最多四层|
|水|火|电|受到*未被格挡*的伤害时，有50%几率使伤害减半|
|电|水|草|成功闪避攻击后有10%几率进行反击（*随机*使用技能）|

- 克制规则：被克制的属性的宝可梦对对方伤害减半，受到的伤害加倍

## 游玩方法

- 运行`play.py`，浏览宝可梦序列，选择输入对应的数字，将宝可梦添加到你的队伍中，一支队伍中的宝可梦不能重复

- 回合开始时玩家先手，从技能中选择一个施放，输入对应数字选择技能

- 若你的宝可梦倒下，按照系统提示从队伍中存活的宝可梦里选择一只上场继续战斗

- 当玩家或电脑队伍中的宝可梦全部倒下时，游戏结束，队伍中仍有宝可梦存活的一方获胜，游戏结束
