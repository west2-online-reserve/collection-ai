# 关于终端

## 遇到终端相关的问题

在编写[Pokemon_Battle](./作业%203/Pokemon%20Battle/)时，对其的非[start](./作业%203/Pokemon%20Battle/start.py)的`.py`文件进行调试，在`if __name__ == "__main__":`设置正确的情况下，使用终端运行时会出现找不到文件的报错，其实由于导入时是使用相对导入`from .xxx import xxx`，而使用绝对导入`from xxx import xxx`时，`start.py`文件又无法直接运行，其原因是终端把当前运行的文件作为主文件，导致相对位置全乱了。最后就是先用绝对导入调试，调试完后再改回相对导入。  
  
除此之外，还在`task0`的[正则表达式](../task%200/Bonus/进阶/5-正则表达式.py)中，遇到过数据残留的问题，根据 ai 的推测，应该是我某次输入`input()`时使用了`ctrl+c`强制关闭，导致数据残留在缓存区，最后点了终端右上角的垃圾桶后，程序才正常运行。  

## 右上角的三角形运行按钮

其实际上是在终端输入了一行命令  

C:\Users\Name\AppData\Local\Programs\Python\Python310\python.exe -u "d:\你的项目路径\main.py"
>这是 ai 告诉我的  

因此，在一些要求用户进行选择的程序中，使用这个按钮会触发无效输入的提示。所以无法通过这个按钮直接重启程序，需要手动`ctrl+c`关闭或者在程序中选择退出。
