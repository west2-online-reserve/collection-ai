### 5.列表推导式

基本结构`放进列表的元素 for 变量 in 可迭代对象 if 条件`  

```python

    squares.append(x ** 2)
# [0, 1, 4, 9, 16]

# 推导式写法
squares = [x ** 2 for x in range(5)]

```

```python
result=[]
```

#### format

##### 基本用法


#### 格式规范

```python
"{:*^+#015,.2f}".format(12345.6789)#"***+12,345.68**"
```

格式规范顺序固定`{:[填充][对齐][符号][#][0][宽度][,][.精度][类型]}`  
  
`*` 使空位用 `*` 填充，可换成其他字符
  
`^` 使输出居中，居左右分别为 `<` ， `>`
  
`+` 使最前面加+,变为正数
  
`#` 使输出变为进制,由于这里是f类型，所以不生效  
> "{:#x}".format(255)        # "0xff"      十六进制带前缀  
"{:#X}".format(255)        # "0XFF"  
"{:#o}".format(8)          # "0o10"      八进制带前缀  
"{:#b}".format(10)         # "0b1010"    二进制带前缀  
ai生成
  
`15` 控制总宽度，因此在居中是左右两边会产生被 `*` 填补的空位,如果使用 `015` 则会在空位用 `0` 填充，但是这里自定义填充优先

`,` 使其输出变为每千分位一个 `,`
  
`.2` 保留两位小数
  
`f` 输出类型，为浮点数

### 装饰器

```python

    return FC

```

将FD作为FB（括号内的函数）代入到FA里面，最后将调用FD的内部函数FC（返回的函数）定义为新的FD  
  
装饰器也可以一次性调用多个，会***从下往上***执行  

```python
def FA(FB):

        FB()
    return FX
def FC(FB):
    def FX():
        FB()
    return FX
def FD(FB):
    def FX():
        FB()
    return FX
@FA#最后执行这个
@FC#再执行这个
@FD#先执行这个
def FE():
```

由于FX和FB都属于局部变量，在定义时离开作用域时局部变量会被消除，故可以重复使用  
  
装饰器也可以传入参数

```python
def FA(FX):

            print(FX)
            FY()  
        return FC
    return FB
@FA(FX=x)
def FD()
```

FA的效果为定义FB,最后返回FB作为最终结果  
FB的效果为定义FC,最后返回FC到FA

@FA由于已经使用(FX=x)定义了第一层FX的内容,后面的FD代入的是第二层FY的内容

### 递归

递归就是函数自己调用自己，最后要有个停止条件  
否则会无限进行下去

```python
def fx(i):
    while i>0:
        i-=1
        return fx(i)
    return i
```

递归相较于迭代，速度慢很多
所以，优先选择迭代，当问题偏向递归时，再选递归
汉诺塔就是递归的例子

```python
1   def h(n,source,target,assist):
2       if n ==1:
3           print(source,"-->",target)
4       else:
5           h(n-1,source,assist,target)
6           print(source,"-->",target)
7           h(n-1,assist,target,source)
```

第 3 行就是放柱子时随着递归进行，分析到一层圆片时进行移动  
第 5 行是分析除最下层外的圆片以初始柱为起始点放到辅助柱子的过程  
第 6 行是在其他圆片都在辅助柱子后把最低下的放到目标柱  
第 7 行就是分析把辅助柱作为出发点，将圆片放到目标柱的过程

## 重写  

可以使用特殊函数名`__init__`
对于输入其中的变量都会应用与整个对象  
且创建对象时,`__init__`函数会自动运行一次  

```python
class C:
    def __init__(self,x,y,z):
        self.x=x
        self.y=y
        self.z=z
    def fx(self):
        return self.x+self.y+self.z#这里直接调用了__init__中的变量
class D(C):
    def __init__(self,x,y,z):
        C.__init__(self,x,y,z):

        #通过继承数据来继承能力
        #能够实现的原因是其形参名一样
```

## "私有变量"

再变量名前加`__`两个下划线，则变成私有变量

```python
class A:
    def __init__(self,x):
        self.__x=x
    def p(self):
        print(x)
    def __func(self):
        pass
a = A(y)
print(a.__x) #无法访问，报错
a.p #y 正常访问
a.__dict__ # {'_C__x':y}
print(a._A__x) #'y' 加密了一点，但不多
a._A__func() # 正常
a.__func()  #报错
a.__b=z #此时变量并不会加密，仍未__b
```

私有变量仅仅是原变量改了名字
当变量开头或结尾为单个`_`  
是约定俗称的内部变量，最好不要轻易修改

### \_\_new__

`__new__`为新建自己类型的对象

向`__new__`中输入了一个文本,`__new__`就会先对他进行加工再创建  
如果我向普通函数输入，会先创建完，在调用函数时在进行加工  
因此可以用`__new__`改一些原先不可变的东西

```python
class A(str):
    def __new__(cls,x):#__new__为创建对象,还无self
        x=x.upper()
        return super().__new__(cls,x)
a= A("abc") #这里被拦截了
print(a)#ABC
```

这里由于为(str)的子类,所以可以使用str的方法  
所有的类都有一个`__new__`函数
定义了 `__new__` 这个特殊函数后，类在实例化时会自动运行它
我们在里面把参数加工好，然后通过 `super()` 调用父类的 `__new__`
父类的`__new__`建立了个传入对象(cls)类型的对象返回。

### Python 魔法方法（运算相关）大全

> 说明：  
>
> * `__xxx__`：正向运算，左操作数触发。  
> * `__rxxx__`：反向运算，左操作数返回 `NotImplemented` 时，右操作数触发。  
> * `__ixxx__`：原地运算，增强赋值触发（如 `+=`），通常返回 `self`。  
> * 比较运算没有反向和原地方法。  
> * 一元运算、类型转换、容器操作通常只有正向方法。

#### 一、算术运算符（二元）

| 运算符 | 正向方法 | 反向方法 | 原地方法 | 说明 |
| --- | --- | --- | --- | --- |
| `+` | `__add__` | `__radd__` | `__iadd__` | 加 |
| `-` | `__sub__` | `__rsub__` | `__isub__` | 减 |
| `*` | `__mul__` | `__rmul__` | `__imul__` | 乘 |
| `/` | `__truediv__` | `__rtruediv__` | `__itruediv__` | 真除法 |
| `//` | `__floordiv__` | `__rfloordiv__` | `__ifloordiv__` | 整除 |
| `%` | `__mod__` | `__rmod__` | `__imod__` | 取模 / 格式化 |
| `**` | `__pow__` | `__rpow__` | `__ipow__` | 幂运算 |
| `@` | `__matmul__` | `__rmatmul__` | `__imatmul__` | 矩阵乘法 |
| `divmod(a,b)` | `__divmod__` | `__rdivmod__` | — | 返回 `(a//b, a%b)` |

| `format(obj, spec)` | `__format__` | 格式化字符串 |
| `hash(obj)` | `__hash__` | 哈希值 |
| `bytes(obj)` | `__bytes__` | 转字节串 |
| `obj()` | `__call__` | 让实例像函数一样调用 |
| `with obj:` | `__enter__` | 进入上下文 |
| `with obj:` | `__exit__` | 退出上下文 |

#### 七、关键规则

1. 正向 vs 反向：  
   `a + b` 先找 `a.__add__(b)`。  
   如果 `a` 返回 `NotImplemented`，Python 才会去调 `b.__radd__(a)`。

2. 原地 vs 重新赋值：  
   `a += b` 先找 `a.__iadd__(b)`。  
   有就原地修改，通常返回 `self`；没有就退化成 `a = a + b`，重新赋值。

3. `NotImplemented` 不是异常：  
   它是告诉 Python「我不支持这个运算，去问对面吧」的信号。  
   不要和 `NotImplementedError` 混淆。

4. 比较运算符：  
   通常只需要实现 `__eq__` 和 `__lt__`，Python 会自动推导其它比较。  
   但 `<`、`>`、`<=`、`>=` 不会自动从 `__eq__` 推导。

5. 自定义类只实现 `__eq__` 时：  
   Python 会自动把 `!=` 变成 `not __eq__`。  
   但其它比较不会自动推导

```python
    def __init__(self, fget=None, fset=None, fdel=None):
        self.fget = fget      #初始化三个函数 
        self.fset = fset      #即占位，将其赋值为None
        self.fdel = fdel      

    def __get__(self, instance, owner):
        return self.fget(instance)      # 拦截读取，调用 fget

    def __set__(self, instance, value):
        self.fset(instance, value)      # 拦截写入，调用 fset

    def __delete__(self, instance):
        self.fdel(instance)             # 拦截删除，调用 fdel

    def getter(self, func):             # 这几行def没有实际用处，仅贴标签
        self.fget = func                #存入函数
        return self                     # 返回自己，支持链式装饰

    def setter(self, func):
        self.fset = func
        return self                     # 返回自己，支持链式装饰

    def deleter(self, func):
        self.fdel = func
        return self                     # 返回自己，支持链式装饰

        self._x = 250
```

## 正则表达式符号使用小总结

1. [ ]：方括号。匹配需要的字符集合，如[1-3]或[123]都是匹配1、2或者3。[0-9a-zA-Z]就是匹配里面任意一个东西
2. ^：脱字符号。方括号中加入脱字符号，就是匹配未列出的所有其他字符，如[^a]匹配除a以外的所有其他字符。
3. \：反斜杠。和python字符串使用规则一样，可以匹配特殊字符本身，如\d表示匹配0到9的任意一个数字字符，而\\d则表示匹配\d本身。
4. \*：星号。匹配前一个字符0到n次，如pytho*n可以匹配pythn、pytoon、pythooooon等。还有其它匹配重复字符的如？、+或{m,n}，其中{n,m}可以灵活使用，它表示匹配n次到m次
5. {x,y}:匹配重复x~y次，如果多于或者少于则匹配失败，返回`None`
6. 揩油加`^`表示判断开头,`$`表示判断结尾,`^$`的范围间必须都匹配，否则返回`None`

```python
re.match(r'\d{6,18}', '123456abc')   # 会匹配 "123456"
re.match(r'\d{6,18}$', '123456abc')  # ❌ 不匹配，因为有 abc
```
