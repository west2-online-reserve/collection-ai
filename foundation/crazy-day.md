#    我疯狂的一天

## 早上
早上七点五十，闹钟响了，我按掉继续睡。八点十分突然惊醒，一看课表，八点有课，赶紧穿衣服洗脸，牙都没刷就冲出宿舍。

到教室八点二十五，老师已经点过名了。我从后门溜进去，坐最后一排。上了十分钟实在困得不行，趴着睡着了，再醒来已经九点四十，下课了。

十点去食堂，早饭午饭一起吃了。点了一份麻辣香锅，花了二十三，感觉有点贵，但实在太饿了，全吃完了。

十一点回宿舍，室友还在睡，我打开电脑准备开始完成[西二在线](https://site.west2.online/)的任务。打开VS Code写了第一行，然后开始刷视频。刷到下午两点。
这是我写的python代码
```
def funa():
    return 'hello,wset_online'
print(funa())
```
两点半觉得不能这样下去了，背着书包去图书馆。在图书馆转了十分钟才找到空位，坐下玩了会手机，三点开始看书。看了两页，困了，趴桌子上睡到四点半。

## 晚上
五点去食堂吃晚饭，吃了碗牛肉面，十四块。吃完回宿舍，室友叫我打游戏，我说打一把就去写作业。结果打到晚上九点。
![牛肉面图片](牛肉面-1.jpg "牛肉面")）

十点终于开始写作业，发现题目都不会。问同学，同学说这题上周就布置了，明天要交。我赶紧抄了室友的，又改了改，十一点半写完。

十二点上床，想着明天一定好好学习。然后刷手机刷到凌晨两点。

这一天，啥也没干成，但感觉特别累。
