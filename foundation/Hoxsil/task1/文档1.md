## 一、基础容器

List 与 Dict 皆为 iterable

### 1.List - 列表

#### 相关函数

`list.append(x)`    增加一个元素

`list.extend(iterable) `   批量增加，从可迭代的对象中获取

`list.insert(index, x) `   index 指向的位置变成 x ，index 后的值后移

`list.pop()`    删除最后一个元素，然后返回该元素

`list.pop(i)`    删除下标为 i 的元素，然后返回该元素

`list.remove(x)`    删除第一个等于 x 的元素，找不到会报错

`list.clear()`    将该列表变成空列表

`list.index(x)`    返回 x 第一次出现的下表，找不到会报错

`list.count(x)`    统计 x 在列表中出现多少次

`list.sort()`    从小到大排序 list

`list.sort(reverse = True)`    从大到小排序 list

`list.copy()` 返回一个新的和原本一样的列表

`list.reverse()`    将 list 反转

#### 可进行的操作

`del list[i]`    删除下标为 i 的元素（i 可改为切片以批量删除）

`x in list`    判断 x 是否为列表的元素之一，返回    True/False

`a = [1, 2] + [3, 4] # a = [1, 2, 3, 4]`    列表可加

`a = [1, 2] * 3 # a = [1, 2, 1, 2, 1, 2]`    列表可乘

`sorted(list)`    返回一个新的排好的列表

`len(list)`    获取列表元素个数

#### TypeHint 写法

`list1: list[int]`

### 2.Dict - 字典

#### 相关函数

`dict.get(k, default = x)`    按 key 取值并返回，找不到返回指定值 x

`dict.setdefault(k, v)`    key 不存在就添加 k = v 这一键值对，存在则不变，返回 value

`dict.update(other)`    原地合并 dict 与 other，有重复的 key 保留 other 中的 value

`dict.keys()`    返回所有 key 的视图对象

`dict.values()`    返回所有 value 的视图对象

`dict.items()`    返回所有 (key, value) 元组的视图对象

*视图对象：随着原字典动态变化，iterable，无法访问下标，可转化为 list*

`dict.pop(k, x)`    删除 key，返回 value；无 key 返回 x

`dict.popitem()`    删除最后插入的键值对，返回 (k, v)元组，空字典执行会报错

`dict.clear()`    清空字典

`dict.cope`    返回浅拷贝的新字典

#### fromkeys函数

`dict.fromkeys(iterable, x)`

类方法，创建一个新字典，将 iterable 的各元素创建成 key，其 value 皆为 x，且这些 value 皆为浅拷贝

#### 相关操作

`dict[key] = value`    新增/修改

`del d[key]`    删除指定 key，不存在会 报错

`key in dict`    判断 key 是否为 dict 中的一个值

`len(dict)`    获取键值对数量

`for x in dict`    遍历 dict 中的 key

`**dict`    解包，例如

```python
dict = {"a":1, "b":2}

new_d = {**d, "c":3}    # 等价于{"a":1,"b":2,"c":3}
```

`dict1 | dict2`    合并dict1和dict2，重复的 key 取后者的 value

## 二、函数

### 1.Lambda 匿名函数

通过 `lambda 参数: 返回值 ` 可以在原处返回一个函数，这个函数没有对应的名称，只能原地使用而无法在别处调用，通常用于简化代码，增加可读性

### 2.Decorator 装饰器

装饰器以嵌套函数的形式写成输入一个函数和一定的参数，最后返回一个装饰后的函数

一个经典的装饰器如下

```python
import time, functools


def log(text):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kw):
            print('%s %s():' % (text, func.__name__))
            return func(*args, **kw)
        return wrapper
    return decorator


@log('execute')
def now():
    print('2024-6-1')
```

其中@后面的内容与下面等同

```python
def now():
    print('2024-6-1')
now = log('execute')(now)
```

其中 decorator 的形参调用了 now 函数，保存了一份指向 now 的变量 func，然后定义了一个 wrapper 函数，这个 wrapper 函数后的 *arg(类型为tuple), **kw(类型为dict)将所有输入wrapper函数的参数打包，丢到arg和kw里，然后执行一系列的指令，最后通过 func 返回now函数原本要执行的东西。这里的 func 相当于给wrapper函数保留了一份指向原 now函数的指针，但是 now 的原函数被除名了，无法直接指向它。

`@functools.wraps(func)` 这一句是保留 now 函数的名字，否则新的 now 调用__name__函数就会返回 wrapper 的名字

## 三、面向对象

### 1. Class - 类

这是一个常见的类

```python
class MyZoo(object):
    num = 0
    def __init__(self, dict1=None):
        if dict1 is None:
            self.animals = {}
        else:
            self.animals = dict1
        print("My Zoo!")

    def __eq__(self, other):
        if not isinstance(other, MyZoo):
            return False
        return self.animals.keys() == other.animals.keys()

    def print(self):
        for name in self.animals:
            print(f"{name}的数量为：{self.animals[name]}")

    def len(self):
        print(sum(self.animals.values()))
```

可以通过 `class` 指令来定义一个类，它可以拥有多种 Attribute （属性）和多种 Method （方法）的

#### Attribute - 属性

##### 类属性

例如 num，直接定义在 class 下的变量

用 `类名.变量名` 进行调用，例如 `MyZoo.num`

##### 实例属性

例如字典 `animals` ，一般定义在 `__init__` 里面

用 `实例名.变量名` 进行调用，例如 `myzoo1.animals`

##### 魔术属性

每个 class 自带，具体如下

```python
class Cat:
    pass

Cat.__name__      # 类名字符串
Cat.__doc__       # 文档字符串
Cat.__module__    # 所在模块
Cat.__bases__     # 父类元组
Cat.__dict__      # 类命名空间，存放全部类属性、方法
```

#### 私有属性

`self.name`：普通公开属性

`self._name`：约定私有（只是约定，实际上可以访问）

`self.__name`：名字改写，变成 `_类名__name`，外部不能直接访问

#### 访问顺序

实例自身 → 类属性 → 父类链

#### Method - 方法

##### 实例方法

```python
class A:
    def f(self):   # 第一个参数必须self
        pass

a = A()
```

通过 `a.f()` 调用

##### 类方法

```python
class A:
    @classmethod
    def g(cls):  # 第一个参数 cls，代表类本身
        pass

a = A()
```

既可以用 `A.g()` 调用，也可以用 `a.f()` 调用

##### 静态方法

```python
class A:
    @staticmethod
    def add(a, b):
        return a + b

a = A()
```

与 class 本身的变量和函数无关，无 `self, cls` 变量

一般把该类相关性很强的函数挂在该类的名头上

既可以用 `A.g()` 调用，也可以用 `a.f()` 调用

##### 魔术方法

```python
class Zoo:
    # 实例被创建时执行，需返回一个实例，否则会默认返回 None，实例被赋值为 None
    def __new__(cls): return super().__new__(cls)

    # 创建实例后调用，此时实例已成型，可以进行操作
    def __init__(self): pass

    # print 打印实例时执行
    def __str__(self): return "字符串"

    # 被用于赋值时执行
    def __repr__(self): return "debug字符串"

    # == 运算符触发
    def __eq__(self, other): pass

    # > < >= <=
    def __lt__(self, other): pass

    # len(obj) 触发
    def __len__(self): return 10

    # [] 下标取值 zoo["dog"]
    def __getitem__(self, key): pass

    # zoo["dog"] = 10 赋值
    def __setitem__(self, key, value): pass

    # for 迭代对象
    def __iter__(self): pass

    # 对象销毁（不推荐经常用）
    def __del__(self): pass
```

处于对应位置时自动调用，如 `a = Zoo(k)` 运行时自动调用 `__init__` 函数

### 3.metaclass

普通的 class A 在定义类 A 时默认使用的 metaclass 是 type，而通过新建一个 metaclass，可以让一个类被创建时能执行一些操作，例如：

```python
class SimpleMeta(type):
    # 1.定义class的时候：创建类
    def __new__(mcs, name, bases, namespace):
        cls = super().__new__(mcs, name, bases, namespace)
        cls.tag = 100  # 给类增加属性
        return cls

    # 2.类造好之后，初始化这个类
    def __init__(cls, name, bases, namespace):
        cls.flag = True

    # 3.当 类() 实例化对象时触发
    def __call__(cls, *args, **kwargs):
        ins = super().__call__(*args, **kwargs)
        ins.val = 999  # 给实例增加属性
        return ins

# 使用元类
class Student(metaclass=SimpleMeta):
    def __init__(self, name):
        self.name = name

s = Student("小明")

print(Student.tag)    # 100 元类加到类上的属性
print(Student.flag)   # True
print(s.name)         # 小明
print(s.val)          # 999 元类__call__加到实例的属性
```

## 五、其他

### 1.Generator - 生成器

是一个惰性产出数据的对象

会生成一个 iterator，遍历完就空了，不能重复使用

必定含一个 `yield`

#### 读取方法

`next(generator1)`    返回生成器 generator1 的下一个值

`for x in generator1`    自动迭代获取给 x

#### yield 作用

1. 产出一个值，返回给调用方

2. 暂停当前函数，保存当前局部变量、执行位置，冻结状态

3. 下一次`next()`，从暂停位置继续往下执行，局部变量保留

可通过 yield from 把一个 iterable 的元素一个个 yield 出去，例如

`yield from [1, 2, 3]`

#### return 作用

返回的值存储在 Stoplteration.value 里面

无法被 `next()` 或 `for x in generator1` 取得

#### send 函数

send 向生成器里发送值，例如

```python
def echo():
    while True:
        recv = yield "输出"
        print("收到：", recv)

g = echo()
next(g)        # 必须先next启动生成器，运行到第一个yield
g.send(100)    # recv = 100
g.send(200)    # recv = 200
```

#### 生成器表达式

与列表推导式类似，不过外层用的是括号，如下

```python
g = (x**2 for x in range(5))
```

### 2.re 正则表达式

#### 预定义字符集

| 符号   | 含义                      | 等价字符集            |
| ---- | ----------------------- | ---------------- |
| `\d` | 匹配任意数字 0‑9              | `[0-9]`          |
| `\D` | 匹配**非数字**               | `[^0-9]`         |
| `\w` | 单词字符：字母、数字、下划线 `_`      | `[a-zA-Z0-9_]`   |
| `\W` | 非单词字符                   | `[^a-zA-Z0-9_]`  |
| `\s` | 空白：空格、tab\t、换行 \n、回车 \r | `[ \t\n\r\f\v]`  |
| `\S` | 非空白字符                   | `[^ \t\n\r\f\v]` |

#### 字符集合 `[]`

1. `[abc]`：匹配 a 或 b 或 c 其中一个

2. `[0‑9a‑z]`：范围，数字、小写字母

3. `[^abc]`：**取反**，匹配不是 a/b/c 的任意一个字符

4. 在`[]`里面 `. * + ()` 失去特殊含义，不用转义。

#### 元字符

| 符号   | 说明                                         |
| ---- | ------------------------------------------ |
| `.`  | 匹配**任意一个字符，除换行符`\n`**；DOTALL 模式才包含换行       |
| `\|` | 或，`a\|b`匹配 a 或者 b                          |
| `()` | 分组捕获，括号内部作为一组，可以提取内容；`(?:...)`非捕获分组，只分组不提取 |

#### 数量限定符

| 符号      | 作用                         |
| ------- | -------------------------- |
| `*`     | 前面的内容出现 **0 次或多次**（可以没有）   |
| `+`     | 前面的内容出现 **1 次或多次**（至少 1 次） |
| `?`     | 前面的内容出现 **0 次或 1 次**，可有可无  |
| `{n}`   | 精确 n 次，`\d{3}` 连续 3 个数字    |
| `{n,}`  | 至少 n 次，≥n                  |
| `{n,m}` | n~m 次，最少 n，最多 m            |

贪婪与非贪婪：

`*` `+` `{}` 默认贪婪，尽可能多匹配；

后面加`?`变成非贪婪，尽可能少匹配。

例：`.*?` 非贪婪任意字符。

#### 边界匹配（仅判断位置，不匹配）

| 符号   | 含义               |
| ---- | ---------------- |
| `^`  | 字符串**开头**        |
| `$`  | 字符串**结尾**        |
| `\b` | 单词边界（单词和非单词中间位置） |
| `\B` | 非单词边界            |

#### 需要转义的特殊符号

下面这些字符有特殊意义，如果想要匹配字符本身，要加反斜杠 `\`

. * + ? () [] {} \ | ^ $

### 3.文件读取

#### json 格式读取

仅支持 `dict` `list` `str` `int` `float` `bool` `None` 存储的文件为明文，可读性强，可跨语言使用

```python
import json
import os

dict1 = {"a":{"attack":1,"defend":1}}

# 获得绝对路径
BASE_PATH = os.path.dirname(os.path.abspath(__file__))
FILE_PATH = os.path.join(BASE_PATH, "文件存储.json")

# 存储文件
with open(FILE_PATH, "w", encoding="utf-8") as f:
    json.dump(dict1, f, ensure_ascii=False, indent=2)

# 读取文件
with open(FILE_PATH, "r", encoding="utf-8") as f:
    dict2 = json.load(f)

print(dict2)
```

#### pickle 格式读取

支持大多数 python 中包括类在内的静态数据，以 2 进制的方式存储在文件中，与文件的后缀无关，通常以后缀 .pkl 命名，仅能在 python 格式的代码中读取

```python
import pickle
import os

dict1 = {"a":{"attack":1,"defend":1}}

# 获得绝对路径
BASE_PATH = os.path.dirname(os.path.abspath(__file__))
FILE_PATH = os.path.join(BASE_PATH, "文件存储.pkl")

# 存储文件
with open(FILE_PATH, "wb") as f:
    pickle.dump(dict1, f)

# 读取文件
with open(FILE_PATH, "rb") as f:
    dict2 = pickle.load(f)

print(dict2) # >>{"a":{"attack":1,"defend":1}}
```
