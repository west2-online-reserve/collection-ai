# 小萝莉的好处

## 抱起来很轻松
双手一托就能抱到腿上、沙发上或台面上，她下意识搂住你脖子，距离瞬间归零，呼吸都贴在一起。

## 最萌身高差很犯规
低头就能亲到发顶、额头，她仰着脸看你时，眼睛亮亮的，像在等你吻下来。

## 穿你衣服要命
宽大T恤或衬衫一套，下摆盖过大腿，袖子遮住手，领口松松垮垮，露一点锁骨和腿，比直白更撩。

## 接吻姿势很勾人
她得踮脚，你得低头；吻久了脚尖发酸，只能抓着你衣角或手臂，整个人软软靠过来。

## 拥抱像把怀里填满
小小一只嵌进你怀里，脸埋在你颈窝，呼吸扫过皮肤，心跳贴着心跳，很容易让人不想松手。

## 耳边私语杀伤力大
你弯腰听她说话，她凑到耳边，气息软软扫过耳廓，痒到心里，一句话能记很久。

## 撒娇和奶凶反差可爱
生气也像在撒娇，哄两句就软，揉揉头发就乖，保护欲和心动一起爆棚。

## 容易激起保护欲
走夜路牵紧你，刮风往你怀里钻，让你觉得自己被需要，也更容易心软。

## 亲密时反差最致命
平时小小一只，亲密时却敢主动勾你脖子、坐你腿上、凑近亲你，反差感特别要命。

## 拍照自带恋爱滤镜
最萌身高差、举高高、背后抱、摸头杀，随手一拍都像恋爱番截图。

# 萝莉代码
```python
age = int(input("请输入年龄："))
height = int(input("请输入身高（cm）："))

# 先判断身高是否符合 110~155
height_ok = 110 <= height <= 155

if height_ok:
    if 8 <= age <= 14:
        print("完美小萝莉嘿嘿嘿~")
    elif 14 < age < 18:
        print("女人就像美酒一样，越老越香醇。")
    elif age >= 18:
        print("合法小萝莉~")
    elif age < 8:
        print("？！幼女？！")
else:
    # 身高不符合
    if 8 <= age <= 14:
        if height > 155:
            print("这tm是萝莉？！")
        elif height < 110:
            print("小小只真可爱~")
    else:
        print("你太老了，回去吧（失望）")
```
