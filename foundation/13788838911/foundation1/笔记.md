### dict(字典)

字典是另一种可变容器，可存储任意类型的对象

每一对用键值key:value用:来分割，每个键值对用,来分割，整个字典包含在花括号中

(1)创建字典：

```python
d={"a":1,"b":2,"c",3}
```

值可以取任意类型，但是键必须是不可变的，例如字符串，数字或者元组

键一般是唯一的，如果重复最后一个键值对会替换前面的，值不需要唯一

(2)访问字典里的值

```python
d={"a":1,"b":2,"c",3}
print(d["a"])     #输出：1
print(d["c"])     #输出：3
```

如果字典中没有访问的键的数据，会输出错误如下：

## 函数

### Lambda匿名函数

Lambda函数被用来创建匿名函数，他可以具有任意数量的参数，但是只能有一个表达式，匿名函数不需要用def来定义完整函数。

Lambda函数通常用于编写单行的函数，经常用于需要函数作为参数传递的情况。

(1)函数特点

- 函数是匿名的，没有名称，只通过赋值给变量或者作为参数传递给其他函数
- 通常只包含一行代码

(2)语法格式

lambda arguments: expression

- lambda为Python关键字，用于定义lambda函数。
- arguments为参数列表，必须在:前，可以是0个。
- expression为表达式，用于计算并返回函数结果

简单示例：

```python
f = lambda: "Hello, world!"
print(f())  # 输出: Hello, world!
x = lambda a : a + 10
print(x(5)) # 输出：15
x = lambda a, b : a * b
print(x(5, 6)) #输出：30
```

接下来是Lambda与内置函数一起使用：

```python
numbers = [1, 2, 3, 4, 5]
squared = list(map(lambda x: x**2, numbers))  #map()函数用于批量处理
print(squared)  # 输出: [1, 4, 9, 16, 25]

numbers = [1, 2, 3, 4, 5, 6, 7, 8]
evennumbers = list(filter(lambda x: x % 2 == 0, numbers))  #filter()函数用于过滤可迭代对象中的元素
print(evennumbers)  # 输出：[2, 4, 6, 8]

from functools import reduce
numbers = [1, 2, 3, 4, 5]
product = reduce(lambda x, y: x * y, numbers) #reduce()函数用于迭代累计
print(product)  # 输出：120
```

### Decorator装饰器

本质上装饰器是一个函数，用于不修改原代码的前提下，动态扩展函数或者类的功能。

(1)基本语法：

```python
def decorator_function(original_function):
    def wrapper(*args, **kwargs):
        # 调用前
        print("执行前")

        result = original_function(*args, **kwargs)

        # 调用后
        print("执行后")

        return result
    return wrapper

@decorator_function
def target_function():
    print("原函数执行")
```

- decorator_function:装饰器函数
- wrapper:包装函数
- @decorator_function:等价于函数替换

也可以写成：

```python
target_function = decorator_function(target_function)
```

(2)使用装饰器

装饰器通过@语法糖应用在函数定义之前：

```python
@time_logger
def target_function():
  pass
```

等价于：

```python
def target_function(){
  pass
}
target_function=time_logger(target_function)

#例如：
def my_decorator(func):
    def wrapper():
        print("函数执行前")
        func()
        print("函数执行后")
    return wrapper

@my_decorator
def say_hello():
    print("hello!")

say_hello()

#输出：函数执行前
#hello！
#函数执行后

```

(3)带有参数的装饰器

如果原函数有参数，需要在 wrapper 中使用 *args, **kwargs：

```python
def my_decorator(func):
    def wrapper(*args, **kwargs):
        print("执行前")
        func(*args, **kwargs)
        print("执行后")
    return wrapper

@my_decorator
def greet(name):
    print(f"Hello, {name}!")

greet("Alice")

#输出：
#执行前
#Hello，Alice！
#执行后
```

注：使用 *args, **kwargs 可以兼容任意参数函数。

例子：

```python
def repeat(num_times):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(num_times):
                func(*args, **kwargs)
        return wrapper
    return decorator

@repeat(3)
def say_hello():
    print("Hello!")

say_hello()

#输出：
# Hello！
# Hello！
# Hello！
```

(4)类形式的装饰器

```python
class SingletonDecorator:
    def __init__(self, cls):
        self.cls = cls      #保留原始的类，csl就是被修饰的类
        self.instance = None #用来存实例，初始时为空

    def __call__(self, *args, **kwargs): #让类的实例可以像函数一样被调用
        if self.instance is None:
            self.instance = self.cls(*args, **kwargs) #空用原始类
        return self.instance

@SingletonDecorator
class Database:
    def __init__(self):
        print("初始化")
#等价于：Database = SingletonDecorator(Database)

db1 = Database()   #输出：初始化 (不为空，新建database对象)
db2 = Database()   #不为空直接返回存在的实例
print(db1 is db2)  #True
```

(5)常用内置装饰器

1、@saticmethod：定义静态方法，不需要self（实例属性）、cls（类属性）第一个参数，不能访问实例，
适合与这个类有关但不需要用到类里的数据的函数。

2、@classmethod：定义类方法，第一个参数是当前类本身（不是实例），可以修改类本身，但不可以修改实例。

3、@property：将方法变成属性

为什么这三个要使用装饰器呢？改变类默认传实例的规则使用新的规则绑定参数。更便于读写。

```python
class MyClass:
    @staticmethod
    def static_method():
        print("静态方法")

    @classmethod
    def class_method(cls):
        print(cls.__name__)

    @property         #负责读
    def name(self):
        return self._name

    @name.setter      #负责写
    def name(self, value):
        self._name = value

MyClass.static_method()  #类可以调用
obj=MyClass()
obj.name="apple"
print(obj.name)
obj.static_method()      #实例也可以调用=
```

## 面向对象

### Class（类）

面向对象的技术简介：

- 类(Class): 用来描述具有相同的属性和方法的对象的集合。它定义了该集合中每个对象所共有的属性和方法。对象是类的实例。
- 方法：类中定义的函数。
- 类变量：类变量在整个实例化的对象中是公用的。类变量定义在类中且在函数体之外。类变量通常不作为实例变量使用。
- 数据成员：类变量或者实例变量用于处理类及其实例对象的相关的数据。
- 方法重写：如果从父类继承的方法不能满足子类的需求，可以对其进行改写，这个过程叫方法的覆盖（override），也称为方法的重写。
- 局部变量：定义在方法中的变量，只作用于**当前实例的类**。
- 实例变量：在类的声明中，属性是用变量来表示的，这种变量就称为实例变量，实例变量就是一个用 self 修饰的变量。
- 继承：即一个派生类（derived class）继承基类（base class）的字段和方法。继承也允许把一个派生类的对象作为一个基类对象对待。例如，有这样一个设计：一个Dog类型的对象派生自Animal类，这是模拟"是一个（is-a）"关系（例图，Dog是一个Animal）。
- 实例化：创建一个类的实例，类的具体对象。
- 对象：通过类定义的数据结构实例。对象包括两个数据成员（类变量和实例变量）和方法。

(6)方法重写
可以在子类重写父类的方法。

**类的私有方法**

        self.__secretCount += 1
        self.publicCount += 1

counter = JustCounter()

### Magic Methods（魔法方块）

(1)在python中，任何以__开头和结尾的函数，都是魔法函数，例如__init__就是一种魔法函数。

特殊方法以两个下划线开始，以两个下划线结束。

(2)介绍

一个类可以通过定义具有特殊名称的方法来实现对特殊语法所引发的特定操作。

这是python实现操作符重载的方式，允许没格雷西行定义基于操作符的特定行为。

调用类的实例化对象方法时自动调用魔法函数。

举一下例子：

```python
class People(object):
    def __init__(self, name, age):
        self.name = name
        self.age = age
        return

    def __str__(self):
        return self.name + ":" + str(self.age)

    def __lt__(self, other):#(小于)
        return self.name < other.name if self.name != other.name else self.age < other.age


if __name__=="__main__":
    print("\t".join([str(item) for item in sorted([People("abc", 18),
        People("abe", 19), People("abe", 12), People("abc", 17)])]))
    print(People("abe", 19)<People("abe", 12))
```

## re正则表达式

re正则表达式是一个特殊的字符序列，它能帮助我们检查一个字符串是否与某种模式匹配。

re模块提供了与这些方法功能完全一致的函数，这些函数使用一个模式字符串作为他们的第一个参数。

(1)re.match函数

re.match尝试从字符串的**起始位置**匹配一个模式，如果不是起始位置匹配成功的话，match()就会返回none。

函数语法：

```python
re.match(pattren,string,flags=0)
```

| 参数 | 类型 | 说明 |
| :--- | :--- | :--- |
| `pattern` | `string` / `RegExp` | 匹配的正则表达式。 |
| `string` | `string` | 要匹配的目标字符串。 |
| `flags` | `string` | 标志位，用于控制正则表达式的匹配方式（如是否区分大小写多行匹配等。 |

我们可以用group(num)或者groups()匹配对象函数来获取表达式。

| 方法 | 说明 |
| :--- | :--- |
| `group(num=0)` | 匹配的整个表达式的字符串。`group()` 可以一次输入多个组号，在这种情况下它将返回一个包含那些组所对应值的元组。 |
| `groups()` | 返回一个包含所有小组字符串的元组，从 1 到所含的小组号。 |

例子：

```python
import re
 
line = "Cats are smarter than dogs"
 
matchObj = re.match( r'(.*) are (.*?) .*', line, re.M|re.I)
# .表示任意字符，*表示重复0次或者多次，？紧跟在*后表示尽可能少的匹配。

if matchObj:
   print ("matchObj.group() : ", matchObj.group())
   print ("matchObj.group(1) : ", matchObj.group(1))
   print ("matchObj.group(2) : ", matchObj.group(2))
else:
   print ("No match!!")
```

(4)re.compile函数

compile函数用于编译正则表达式，生成一个正则表达式对象，可以给match(),search()以及findall()等函数使用。

语法格式为：

| 参数 / 标志位 | 说明 |

- end([group]) 方法用于获取分组匹配的子串在整个字符串中的结束位置（子串最后一个字符的索引+1），参数默认值为 0；
- span([group]) 方法返回 (start(group), end(group))。

### 列表推导式

列表推导式是 Python 中用于创建列表的一种简洁而优雅的方法。通过列表推导式，可以从一个或多个可迭代对象（如列表、元
组、字符串、集合等）中生成一个新的列表，同时可以在生成过程中对元素进行过滤和转换。
列表推导式不仅能使代码更加简洁，还能提升可读性和执行效率。

基本语法：

```python
[表达式 for 元素 in 可迭代对象 if 条件]
```

- 表达式：它是你希望对每个元素进行的操作或转换。
- 元素：表示当前循环到的元素。
- 可迭代对象：你要遍历的对象，比如列表、元组、字符串等。
- 条件（可选）：一个过滤条件，只有满足条件的元素才会被包含在生成的列表中。

例子：

```python
numbers = range(10)
result = [x**2 if x % 2 == 0 else x**3 for x in numbers if x > 0]
print(result)  # 输出: [1, 4, 27, 16, 125, 36, 343, 64, 729]
```

## generator生成器

在 Python 中，使用了 yield 的函数被称为生成器（generator）。

yield 是一个关键字，用于定义生成器函数，生成器函数是一种特殊的函数，可以在迭代过程中逐步产生值，而不是一次性返回所有结果。

跟普通函数不同的是，生成器是一个返回迭代器的函数，只能用于迭代操作，更简单点理解生成器就是一个迭代器。

当在生成器函数中使用 yield 语句时，函数的执行将会暂停，并将 yield 后面的表达式作为当前迭代的值返回。

然后，每次调用生成器的 next() 方法或使用 for 循环进行迭代时，函数会从上次暂停的地方继续执行，直到再次遇到 yield 语句。这样，生成器函数可以逐步产生值，而不需要一次性计算并返回所有结果。

调用一个生成器函数，返回的是一个迭代器对象。

下面是一个简单的示例，展示了生成器函数的使用：

```python
def countdown(n):
    while n > 0:
        yield n  # 1. 暂停并返回当前的 n
        n -= 1   # 2. 下次恢复时，从这里继续向下执行
 
# 创建生成器对象
generator = countdown(5)
 
# 通过迭代生成器获取值
print(next(generator))  # 输出: 5
print(next(generator))  # 输出: 4
print(next(generator))  # 输出: 3
 
# 使用 for 循环迭代生成器
for value in generator:
    print(value)  # 输出: 2 1
```
