# 终端是什么

Terminal，终端是通过输入命令来操作电脑的一种方式。可以用来做一些常用的操作比如创建文件夹、创建文件、移动文件、关机、锁屏等等。

## 问题

### 终端会出现多种代码报错提示

这是因为终端启动动了Python解释器逐行读取代码，一旦遇到错误就立马停止执行，把错误信息打印到终端。这里的终端相当于是用来显示你的代码错误。

### 终端开头会有不同的提示词

他叫做提示符，类似“C:\Users\你的名字>”或者“yourname@computer:~/project $”这代表了你现在所在的位置。

举例来说“C:\Users\小明\Desktop>”,

“C:”表示在哪个磁盘，

“\Users\小明\Desktop”表示当前所在的目录，

最后的“>”表示你可以输入命令了。

当提示符变成“>>>”表示已经进入Python解释器了，这个时候你输入的不是系统命令而是Python代码。

## VScode中的三角形

1.看你当前打开的是哪个 .py 文件

2.用 VS Code 右下角选中的那个 Python 解释器

3.在 VS Code 底部的 集成终端​ 里自动执行：
    ```python 当前文件.py```

4.print 输出、报错 traceback 全都在这个终端里。

对比自己打开终端，可以省去cd的步骤，但一般也是在当前文件所在目录。
