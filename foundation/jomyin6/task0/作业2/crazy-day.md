# 疯狂的一天：当我的生活开始自动运行

## 从一个普通的早晨说起

早上 7 点，闹钟响了。我闭着眼睛摸到手机，原本只想再睡 5 分钟，却误点了昨晚写好的自动化程序。

下一秒，音箱开始播放摇滚乐，台灯闪个不停，电脑屏幕上弹出一句话：“早安，今天也要高效生活！”

我瞬间清醒了。看来，今天的第一个任务不是学习 AI，而是阻止 AI 替我安排人生。

![早晨的自动化混乱](image-1.png)
## 失控的智能早餐

### 咖啡机的坚持

走进厨房，我发现咖啡机已经连续做了 3 杯咖啡。原来，我把程序里的“工作日执行”误写成了“每分钟执行”。

面对第四杯即将出炉的咖啡，我终于找到了停止按钮。厨房恢复安静，我却已经开始怀疑，所谓自动化，是不是把一个小错误自动重复很多次。

### 冰箱的建议

我打开冰箱，想拿一片面包，却看到便签上写着：“鸡蛋剩余 2 个，建议补货。”

这是我昨天测试 AI 时打印的购物建议。建议本身没问题，但我已经买了 20 个鸡蛋，只是忘记更新记录。

我给自己煎了 2 个鸡蛋，决定暂时相信眼睛。

桌上摆着几杯咖啡、一盘煎蛋，以及一台还没来得及合上的电脑。

程序运行得很成功，我的早餐却差点失控。

![失控的智能早餐](image-2.png)

## 下午的 Git 救援行动

早餐过后，我决定完成第一次 Git 练习。我新建了学习文件夹，写好文章，然后准备保存一个版本。

### 第一次提交

我打算依次运行下面几条命令。之后整理格式时，可以将这些命令放在同一个代码块中。

```bash
git init
git add crazy-day.md
git commit -m "Add my crazy day story"
```

按下回车后，终端提示提交成功。那一刻，我终于有了一个可以回头查看的版本。

### 第二次修改

高兴了不到 10 分钟，我就误删了一段最喜欢的文字。幸好，刚才已经完成提交，我可以查看之前的内容，把那段文字找回来。

找回文字后，我认真检查了文件名。这次我决定，先把本地文件整理好，再上传到 GitHub。

遇到不理解的命令时，我会打开 [Git 官方网站](https://git-scm.com/)，查一查它的用途。虽然阅读文档需要耐心，但总比对着终端乱试更踏实。

随后，我打开 [GitHub](https://github.com/)，准备把这篇文章上传到自己的学习仓库。从今天开始，每一次练习都可以留下一份记录

## 今日事件记录

| 时间      | 事件                | 收获                             |

| 早上 7 点 | 误启动自动化程序    | 运行前先确认触发条件             |

## 晚上，我决定慢一点

晚上 9 点，我重新读了一遍这篇文章。早上那场混乱，现在看起来已经有点好笑了。

我原本以为，学会几个工具就能立刻提高效率。经过这一天才发现，工具会认真执行我的指令，包括那些没有想清楚的指令。

关机前，我把明天的闹钟设好，又检查了一遍自动化程序的开关。

这一次，我只设置了一个普通闹钟。
