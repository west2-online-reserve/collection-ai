## 面向对象

### 类-实例-方法

先讲类

最简单的部分，类用 `Class` 定义

```python
class Member(object)
    def __init__(self,name,age):
        self.name = name
        self.age = age
```

可以当作自定义数据结构看，其中魔术方法 `__init__` 作用为初始化实例，给实例后面的两个属性。

`Object` 指向这个类继承的类，这是所有类最后会继承的类，所以没有想继承的就写这个，或者不写也行。

```python
A = Member("abc","123")
print(f'{A.name},{A.age}')
```

使用类作为数据类型的`A`就是实例

这个时候输出的就是A的属性 结果是 `abc 123`

每个都这么写纯石山，感觉不如列表，可以写方法

```py
class Member(object)
    def __init__(self,name,age):
        self.name = name
        self.age = age
    def printmessage(self):
        print(f'{self.name},{self.age}')
```

这个时候再写只需要 `A.printmessage()`就行了

### 继承--多态（还有实例属性&类属性）

继承就是继承继承对象的所有方法和属性比如：

```py
class animal(object):
    def __init__(self,name="动物"):
        self.name = name
    def threat(self):
        print(f"{self.name}哇嗷")
class bigdog(Animal):
    pass
A = bigdog("大狗")
A.threat()
```

这个时候 `threat` 依旧可用，并且可以发现 `name` 也能用

如果想要大狗叫起来，可以在大狗的类里面再写一个 `threat`

```py
class bigdog(Animal):
    def threat(self):
        print(f"{self.name}叫")
A = bigdog("大狗")
A.threat()
```

因为对于属性和方法，python的查询顺序是从子类到父类，所以会直接调用大狗的叫法

这时候大狗就叫了，但是假如不输入名字依旧会用animal，但是子类里面没有`self`所以只能再写一遍`__init__`但是都继承了还写一遍那我不是白继承了吗？因此继承有不一样的写法

### 魔法方法

一大堆，全讲了肯定不行，因为我是手打。

这里介绍4个 其中一个早就见过了，他们分别是：

`__init__` `__str__` `__eq__` `__len__`

简单的说，这些魔法方法就是在调用其他函数时会执行的

`__init__` 在创建实例时会自动执行

`__str__` 在 `print` 的时候会执行

`__eq__` 在比较不同实例是否相等的时候会自动执行

`__len__` 在使用 `len()` 的时候会自动执行。

看不懂？那说明你是个人，接下来看例子:

```py
class taffy(object):
    member=[]
    def __init__(self,name="taffy"):
        self.name = name
        if self.name not in taffy.member
            taffy.member.append(self.name)
    def __str__(self):
        return f'灌注{self.name}谢谢喵'
    def __len__(self):
        return len(self.member)
    def __eq__(self,other):
        return self.name == other.name
A = taffy()
B = taffy()
if A == B:
    print(A)
    print("是相同的塔菲喵")
    print(f"一共有{len(A)}个taffy喵")
```

输出结果如下：

```py
灌注taffy谢谢喵
是相同的塔菲喵
一共有1个taffy喵
```

应该能看懂了，不过值得注意的是：`__str__`只能返回字符串 `__eq__` 没有的话在比较大小时会报错。

### 装饰器

依旧语法糖，调试的时候用。本质上是在函数运行前后多做一点事情

```py
import time
def decorater_time(func):
    def wrapper():
        a=time.perf_counter()
        func()
        print(str(time.perf_counter()-a)+"s")
    return wrapper

@decorater_time
def call():
    print("ababababa")

call()
```

上面是一个记录运行时间的装饰器，装饰器格式：

```py
def my_decorator(func):
    def wrapper():
        print("执行前")
        func()
        print("执行后")
    return wrapper
```

如果原函数有参数改成：

```py
def my_decorator(func):
    def wrapper(*arg,**kwargs):
        print("执行前")
        result = func(*arg,**kwargs)
        #用于接受所有参数
        print("执行后")
        return result
        #因为函数有返回值的话如果不这么写返回值就没了
    return wrapper
```

## 生成器

第一种生成器是把上面的列表推导式换成小括号，返回的值变成一个一个返回，不是列表了。

第二种生成器借助 `yield` 在自定义函数里定义

```py
def triangles(max):
    count = 1
    res=[1]
    while count<=max:
        temp = []
        for i in range(count+1):
            if i == 0 or i == count:
                temp.append(1)
            else:
                temp.append(res[i]+res[i-1])
        yield res
        res = temp
        count += 1
```

结束时保存当前`yield`结果并且返回，下一次执行会从yield继续

调用用这样的：

```py
for row in triangles(4):
    print(row)
```

values = ["Alice","千年技术学院"]
