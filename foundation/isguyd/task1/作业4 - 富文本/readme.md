# 介绍

这个作业四是一个能读取txt的命令行gal

有打字机效果，按键跳过，自动读档存档，手动不支持

txt支持两选项分支，跨文件的个人线

不支持好感度

## txt格式要求

共通线的文件名必须为 `scripts.txt`

分支需要写成：

```txt
#A 选项A
·······
#B 选项B
·······
#END
```

（全大写）

进线为了编辑方便，写了一个不一样的

```txt
#ROUTE yuki
```

会自动打开 yuki.txt，并提示进线“当前路线：yuki”

这个东西是测试用的，想输出请写文本里。

另外#开头的行不管写了什么都会被跳过（不是上述指令的话），可以当作注释，章节名也可以当成正常句子直接输出，嗯对。

## 可能需要

用ds生成了一个测试文本，在这个目录的`scripts`文件夹下，复制出来就可以玩了。

这个项目还很简陋，所以所有文件都会在这个目录下，包括存档。

另外，这个项目有一些能算是bug的东西，因为我的读取方法是检查行开头是不是`#A`之类的东西，所以如果写错，敲成`#AB`的时候，B会被输出。

（空格都被忽略掉了，放心大胆用）
