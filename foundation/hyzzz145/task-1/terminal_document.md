## 右上角的三角形运行按钮

VS Code 右上角的三角形按钮通常表示**运行当前文件或当前项目**。点击后，编辑器会使用配置好的 Python 解释器执行代码，运行结果和错误信息一般会显示在下方的终端或运行窗口中。

运行按钮方便快速查看程序效果；如果要运行其他文件、传入参数，或指定运行方式，也可以在终端中输入命令。
