# 学习笔记

+ ints = [x for x in lst if isinstance(x, int)] 这是一种格式，其中第一个 x 是说这是列表元素，第二个 x 是在 lst 中，是整型的元素。
+ 遍历删除可迭代对象时，可以先用列表复制一份。
+ l.extend(), 是将可迭代对象的元素依次加入，而append是将一整个对象都加入进去。
+ randow 库，里面的 shuffl(list), 可以随机打乱列表。
+ utf-8, 支持绝大部分语言。
+ 装饰器是一种函数，返回值为函数，在你想装饰的函数面前加上@装饰器名字，就能让你想装饰的函数，变成装饰器里面的样子。
+ *args 和 **kwargs，前面可以容纳多个未知量，后面可以容纳多个字典数据，用以传入不同函数。
+ sort(key=函数,reverse=False), 其中 key 是排列规则，reverse 是是否翻转，key 的函数是给x评估价值，然后排序，但是 x 不会变。
+ 匿名函数 lambda x：f(x),其中 lambda 是关键字，x是参数，f(x)是表达式兼返回值，只能写一句话。
+ 类的魔术方法跟 c++ 的重载挺像的，然后每个函数都要有个self，然后每个魔术方法的触发方式不用。
