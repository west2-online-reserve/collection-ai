# 学习笔记

## 容器

+ list

1. 遍历删除可迭代对象时，可以先用列表复制一份，避免因为删除而导致的遍历错误。
2. 可以将字典的key和value转化为list
3. 可以使用切片l[a: b: c],其中a是起始位置（默认为开头），b为结束位置（默认为结尾），c为步长
4. 列表推导式：l=[表达式 for 变量 in 可迭代对象 if 条件],这样相当于for循环，返回一个新列表

+ dict

1. 字典选取元素的时候最好用get(key,默认值)，因为这样可以在创建字典时，如果有几个特例情况之外的key下的value的值都一样的话，就可以直接设置一个default作为默认值
2. 结合list的1和2，当我们要遍历删除字典的元素的时候，可以先用列表复制一份

## 函数lambda

定义：匿名函数lambda x：f(x),其中lambda是关键字，x是参数，f(x)是表达式兼返回值，只能写一句话。

## 装饰器

装饰器是一种函数，返回值为函数，在你想装饰的函数面前加上@装饰器名字，就能让你想装饰的函数，变成装饰器返回值的样子。

## 面向对象

+ 魔术方法：类的魔术方法跟c++的重载挺像的，然后就是函数都要有个self，然后每个魔术方法的触发方式不用，如：init,就是直接类名加（数据），str,直接print（对象）就可以......
+ 基类和继承类：基类就是这个类都包含的数据和都要有的方法；继承类就是继承了基类的东西并且自己可以有别的数据和方法，并且可以重写方法
+ 思想：我认为主要就是创造一个对象，然后把数据和方法封装进去，后续更好用，并且与其他对象区分开来
  
## re 正则表达式

这个是一个处理文本的方式，帮我们提取文本中想要提取的东西或者验证一串文本是否符合要求，以下是总结的一些表达式：

| 需求 | 正则表达式 | 说明 |
| --- | --- | --- |
| 查找整数 | r"\d+" | 一个或多个数字 |
| 查找连续小写字母 | r"[a-z]+" | 一个或多个小写字母 |
| 提取日期 | r"\d{4}-\d{2}-\d{2}" | 形如 2026-10-16 |
| 提取简单邮箱格式 | r"[\w.+-]+@[\w.-]+\.\w+" | 仅适用于简单筛查 |
| 查找空白字符 | r"\s+" | 一个或多个空白字符 |
| 删除首尾空白 | r"^\s+\|\s+$" | 可以用 re.sub() 去除 |

## 列表推导式

l=[表达式 for 变量 in 可迭代对象 if 条件],这样相当于for循环，返回一个新列表

## Type hint

可以帮助我们知道这个数据的类型，和函数的返回值，相当于注释，以下是其格式上的规范：

+ 变量名: 类型 = 值
+ def 函数名(参数名: 参数类型) -> 返回类型:
+ 容器名: 容器类型[元素类型,...]

## generator 生成器（yield）

+ 生成器与其它容器的区别是不会把数据全部展现出来，而是一个一个生成
+ yield的作用相当于暂停，并生成值
