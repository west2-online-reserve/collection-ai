# 对于终端的基本使用

+ 使用的地方：在学习的过程中用到终端的地方有：运行python文件、使用pip下载库、git push、git clone的时候用到了。
+ 本质：相对于我们把命令输入到电脑，然后操作系统找到相应的程序，然后执行
+ 遇到的问题：
  1. 环境配置：如果python没有环境配置的话，终端没办法找到python.exe在其它文件下的位置，我们每一次运行python文件的时候都要我们就要先把python.exe的路径写出来才能运行，很麻烦
  2. 命令要输入完全正确不然直接没办法执行
  3. 在输入python文件的时候，有的时候无法运行，是因为文件的路径错了，要cd到正确的文件下面
+ vscode上面的三角形，本质是自动帮我们在终端上写好命令，然后执行
