# 命令行宝可梦对战小游戏

一个用 Python 写的回合制宝可梦对战小 Demo：玩家选两只宝可梦组队，与电脑随机对战，回合制选技能出招、属性克制、异常状态、特性都有。

---

## 运行方式

在 `pk` 目录下执行：

```bash
python myself_play.py
```

> 命令行交互，全程用数字选择。

---

## 玩法流程

1. **组队**：从 5 只宝可梦里选 2 只组成你的队伍（输入数字，空格分隔，例如 `1 3`）；电脑随机选 2 只。
2. **首发**：双方各从队伍里选 1 只出战。
3. **回合**：
   - 打印双方血量与状态；
   - 触发"出招前"特性（水系激流等）；
   - 你选一个技能，电脑随机选技能，双方出招；
   - 回合结束结算异常状态（中毒 / 寄生 / 烧伤等）。
4. **换人**：当前宝可梦濒死时，从队伍里换下一只；队伍空了则该方判负。
5. **胜负**：一方队伍全部倒下，另一方获胜。
6. **退出**：在任何输入处输入 `exit` / `quit` / `退出` 即可结束对局。

## 异常状态

| 状态 | 效果 |
| --- | --- |
| 中毒 | 每回合结束损失 10% 最大 HP |
| 寄生 | 每回合结束损失 10% 最大 HP，并把等量伤害回给自己 |
| 烧伤 | 每回合结束损失 10 HP |
| 麻痹 | 25% 概率当回合无法出招 |
| 蓄力 | 下回合无法选技能，自动释放蓄能爆炎 |
| 伤害减免 | 受到的伤害按比例降低（护盾 / 激流） |

---

## 各系特性

- **草系**：回合结束时回复 10% 最大 HP（茂盛）。
- **水系**：出招前 50% 概率触发激流，本回合受到的伤害降低 30%。
- **火系**：每次造成伤害后攻击 +10%（最多叠到原攻击的 140%）。
- **一般系**：回合结束"心情不定"，随机小幅度加减攻击 / 防御 / 闪避。
- **电系**：你攻击电系对手却 miss 时，电系一方获得一次额外行动机会。
