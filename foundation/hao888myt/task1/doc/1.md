# 简单的整理

## List

```python
nums = [1, 2, 3]
nums.append(4)              # 在末尾添加4
nums.insert(0, 0)           # 在index=0的地方插入0
nums.pop()                  # 删除最后一个元素
nums[1:3]                   # 切片（左闭右开）
nums[::-1]                  # 反转
nums.sort(key=lambda x: -x) # 排序

first, *rest = [1, 2, 3]    # 解包 → first=1, rest=[2,3]

for i, v in enumerate(["a", "b"]): ...   # 索引 + 值
for a, b in zip([1,2], [3,4]): ...       # 并行遍历
```

## Dict

```python
user = {"name": "Alice", "age": 25}
user.get("email", "N/A")          # 安全访问
user["email"]                     # 不是那么安全
user.setdefault("tags", []).append("vip")   # 语法糖,有tag就放着,没tag就加,然后加个vip
user.items()                      # 所有的键值对

d3 = d1 | d2                      # 合并字典
{x: x**2 for x in range(5)}       # 字典推导式

from collections import defaultdict, Counter

d = defaultdict(list)             # 指定默认工厂是 list
d["a"].append(1)                  # 键不存在？自动生成
d["a"].append(2)
d["b"].append(9)                  # d:{"a": [1, 2], "b": [9]}
Counter("aasssdjkl").most_common(2)  # 输出最多的2个元素
```

## Lambda

算是匿名函数,适用于一万个需要输入调用只会用一次的函数的方法

```python
words.sort(key=lambda w: len(w))
list(map(lambda x: x * 2, [1, 2, 3]))             # [2, 4, 6]
list(filter(lambda x: x % 2 == 0, [1, 2, 3, 4]))  # [2, 4]
```

## Decorator

给函数加个函数包装,还挺方便

```python
def one_decorator(func):
    def wrapper():
        print("调用前")
        func()
        print("调用后")
    return wrapper

@one_decorator
def say_hi():
    print("Hi!")

say_hi()
# 调用前
# Hi!
# 调用后
```

```python
# . 任意字符
# \d / \w / \s 数字 / 字母数字下划线 / 空白
# * / + / ? 0+ / 1+ / 0或1
# {n,m} n~m 次
# ^ / $ 行首 / 行尾
# [] / () / | 字符集 / 分组 / 或

import re

text = "订单A123，金额456元，共789件"
re.findall(r"\d+", text)
# ['123', '456', '789']

text = "Hello World, Python is fun"
re.findall(r"\w+", text)
# ['Hello', 'World', 'Python', 'is', 'fun']

def is_email(s):
    return bool(re.fullmatch(r"[\w.]+ @ [\w.]+ \. \w+", s))

is_email("alice@example.com")   # True
is_email("not-an-email")        # False
```

## 列表推导式

啥是推导式呢?
就是按条件遍历一个可遍历对象(比如像list,dict之类的),然后执行某些操作的式子

```python
# 列表推导式
[x**2 for x in range(5)]
# [0, 1, 4, 9, 16]
```

## 生成器

和**迭代器**有一定区别,**生成器**是用到哪存在哪

```python
def count_up(n):
    i = 0
    while i < n:
        yield i                 # 先暂停再传值喵,等next传下一个值
        i += 1

for x in count_up(5): print(x)  # 0 1 2 3 4

g = count_up(3)
next(g)                         # 0
```
